# Example tables

These fictional examples are used in Super Table screenshots. Names, tasks, dates, and artwork are demo content.

| Example | What it demonstrates |
| --- | --- |
| [Launch Planner](Launch%20Planner.md) | Typed fields, colored choices, multiple views, AND filters, sorting, and grouping. |
| [Creative Library](Creative%20Library.md) | Multiple attachments, image previews, tags, checkboxes, and Markdown tasks. |

Use a test vault with Super Table enabled. Copy both notes and the `assets/` folder into the vault root, then open either note in Reading view or Live Preview. The attachment paths in Creative Library are relative to the vault root. To try only Launch Planner, its note is enough. The plugin interface follows your Obsidian language setting.

The three SVG files in `assets/` are original artwork supplied with these examples. They use no remote images or external resources.

See the [user guide](../USER_GUIDE.md) for controls and saving behavior.
