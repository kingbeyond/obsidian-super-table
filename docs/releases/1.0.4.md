# 1.0.4

## English

### Compatibility

- The minimum supported Obsidian version increases from 1.8.7 to **1.13.0**. Update Obsidian before installing this release.
- The **Convert Super Table to Markdown** command ID changes from `super-table:convert-super-table-to-markdown` to `super-table:convert-to-markdown`. Reassign any custom hotkey for this command and update external command references. Its displayed name and conversion behavior stay the same.

### Improved

- Simplifies settings, language detection, view memory, and attachment imports by using the APIs available in the supported Obsidian versions. Existing table data remains compatible; save-conflict and import-failure protections are preserved.

### Fixed

- Removes the temporary copy field and restores focus even when the clipboard fallback command fails.

## 简体中文

### 兼容变化

- 最低支持的 Obsidian 版本从 1.8.7 提高到 **1.13.0**。安装此版本前，请先更新 Obsidian。
- **将 Super Table 表格转换为 Markdown** 的命令 ID 从 `super-table:convert-super-table-to-markdown` 调整为 `super-table:convert-to-markdown`。请重新绑定该命令的自定义快捷键，并更新外部命令引用；显示名称及转换行为保持原样。

### 改进

- 使用支持范围内的 Obsidian API，简化设置、语言读取、视图记忆及附件导入。已有表格数据继续兼容，保留保存冲突及导入失败保护。

### 修复

- 剪贴板回退命令失败时，仍清理临时复制输入框并恢复原有焦点。
