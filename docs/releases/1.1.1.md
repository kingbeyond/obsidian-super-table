# 1.1.1

## English

### Improvements

- Start editing text and number cells by typing, with Chinese IME support.
- Match Obsidian's Markdown list indentation and spacing in text-cell previews, including nested lists and paragraphs within list items.
- Preserve paragraph line breaks, blank lines, and code-block formatting in text cells across Live Preview and Reading view.

### Fixes

- Preserve the saved value until editing is confirmed; invalid or incomplete numeric input does not replace it.
- Keep the caret and composition draft aligned with the selected cell.

## 简体中文

### 改进

- 选中文本或数字单元格后可直接输入替换，并支持中文输入法。
- 文本单元格中 Markdown 列表的缩进与间距和 Obsidian 一致，涵盖嵌套列表及列表项内的段落。
- 在实时预览和阅读视图中保留文本单元格的段落换行、空行和代码块排版。

### 修复

- 编辑确认前保留原值；无效或未完成的数字输入不会覆盖已保存内容。
- 修复输入法编辑期间单元格光标与草稿的对齐问题。
