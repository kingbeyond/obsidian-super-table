# 1.1.2

## English

### Improvements

- Copy an entire table and paste it into a note; the copy can be edited independently of the original.

### Fixes

- Prevent cell focus from jumping during rapid clicks on text cells.
- Preserve the height of tall tables when saving in Live Preview.

## 简体中文

### 改进

- 支持复制整张表格并粘贴到笔记；副本可与原表独立编辑。

### 修复

- 修复快速点击文本单元格时焦点跳转的问题。
- 修复实时预览中保存时较高表格的高度变化问题。
