# 1.1.0

## English

### New

- Search cells in the current table view, highlight matches, and navigate between them, including results inside collapsed groups.

### Improved

- Keep empty values last in both ascending and descending sorts.
- Preserve the table viewport when editing cells, adding rows, and undoing or redoing changes.

### Fixed

- Preserve text selection and editing when releasing the pointer at a cell edge.

## 简体中文

### 新增

- 支持搜索当前表格视图中的单元格，突出显示并逐项跳转，也可定位折叠分组中的结果。

### 改进

- 升序和降序排序时，空值均排在末尾。
- 编辑单元格、新增行及撤销或重做时，保留表格视口位置。

### 修复

- 从单元格边缘松开指针时，保持文本选择和编辑状态。
